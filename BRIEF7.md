# Fase 7: "Chiedi" dentro PDF Penna, via Mac Studio (Qwen locale gratis + Claude con l'ABBONAMENTO Max di Marco, niente API a pagamento)

## Architettura
iPad (PWA https://bifulcma.github.io/pdf-penna/) --https via Tailscale Serve--> **bridge sul Mac Studio** (porta locale 8787) -> due backend:
- `qwen`: Ollama locale (http://127.0.0.1:11434, API /api/chat, streaming). Modello autodetect da `ollama list` (primo che contiene "qwen", configurabile).
- `claude`: la CLI ufficiale `claude -p` (abbonamento Max già loggato sullo Studio), senza tool: `--tools ""` (verifica i flag esatti con `claude --help`), `--no-session-persistence`, `--model` scelto (opus/sonnet), prompt via stdin, output in streaming (`--output-format stream-json` o text) -> inoltra come SSE. Uso strettamente personale, un solo utente; limita concorrenza a 1-2 richieste e metti timeout.
Il bridge NON deve mai far eseguire azioni sul Mac: solo testo in/testo out.

## 1. Bridge (cartella `studio-bridge/` nel repo)
- Server in **Python 3 stdlib** (zero dipendenze, macOS lo ha) o Node se già presente: decidi tu, ma zero install. Endpoint: `GET /health` (modelli disponibili qwen + claude ok), `POST /ask` {provider:'qwen'|'claude', model?, system?, messages:[{role,content}]} -> streaming SSE di testo. CORS solo per origin `https://bifulcma.github.io`. Autenticazione: header `Authorization: Bearer <TOKEN>`; il TOKEN è generato dallo script di installazione (32 byte casuali), salvato in `~/.studio-bridge/token` (chmod 600) e MOSTRATO UNA VOLTA a fine installazione per essere incollato nell'app. Ascolta solo su 127.0.0.1. Limite dimensione richiesta (es. 2 MB) per contesti lunghi.
- `install.sh` (una riga da lanciare sullo Studio: `curl -fsSL https://raw.githubusercontent.com/bifulcma/pdf-penna/main/studio-bridge/install.sh | bash`): idempotente; controlla python3, ollama, claude, tailscale (messaggi chiari in italiano se manca qualcosa); copia i file in `~/.studio-bridge/`; crea LaunchAgent `com.marco.studio-bridge` (RunAtLoad, KeepAlive); esegue `tailscale serve --bg --https=443 http://127.0.0.1:8787` (se il comando richiede abilitare HTTPS/MagicDNS nella console Tailscale, stampa istruzioni chiare e il link); stampa a fine: URL https del Studio (`https://<nome>.<tailnet>.ts.net`) + TOKEN + "incolla questi due valori in PDF Penna > Impostazioni > Assistente". Prevede anche `uninstall.sh`.
- Testa il bridge sul Mac corrente (mac mini: ha `claude`, NON ha ollama): per qwen usa un finto Ollama locale nei test; per claude fai una vera chiamata `claude -p` con `--tools ""` e una domanda banale. Test: auth mancante->401, CORS, streaming, timeout, input enorme, backend non disponibile -> errore leggibile.

## 2. App (PWA)
- Impostazioni > **Assistente**: campi URL del bridge + token (salvati solo in localStorage/IndexedDB del dispositivo), pulsante "Prova connessione" (chiama /health, mostra stato: Qwen ✓ / Claude ✓), scelta sorgente predefinita: "Studio · Qwen (gratis)" / "Studio · Claude (abbonamento)" e modello.
- **Pulsante "Chiedi"** (icona scintilla) nel menu sulla selezione di testo e nella barra: pannello a comparsa (bottom sheet su iPad/iPhone, stile coerente crema/terracotta, tema scuro ok) con: azioni rapide (Spiega · Riassumi · Traduci in italiano · Obiezioni · Domanda libera), selettore sorgente Qwen/Claude, risposta in streaming con rendering markdown semplice, pulsanti **Salva come commento** (aggancia la risposta come commento sulla selezione, già esistente dalla fase 6), **Copia**, **Riprova**.
- Azioni sulla pagina corrente e sul documento: "Riassumi questa pagina", "Domanda sul PDF" (usa il testo estratto con pdf.js; per il PDF intero invia solo i passaggi rilevanti: ricerca per parole chiave già esistente + pagine vicine, entro un budget di caratteri; dichiara nel pannello quante pagine ha incluso).
- Se il bridge non risponde: messaggio semplice ("Lo Studio non risponde: è acceso? Tailscale è attivo sull'iPad?"). Mixed content: l'URL deve essere https; valida l'input.
- Privacy: avviso chiaro una volta sola "Il testo selezionato viene inviato al tuo Mac Studio (e, se scegli Claude, a Anthropic con il tuo abbonamento)". Mai inviare nulla senza azione esplicita dell'utente.
- Modalità offline/senza bridge configurato: il pulsante Chiedi spiega come configurarlo; il resto dell'app invariato.
